Flexbox: flex-shrink & flex-basis Demo

1. Two 220px boxes inside a 340px container (total needed: 440px)

Both have flex-shrink: 1 (default) → both squish to 170px:

Box A (220px, shrink: 1)
Box B (220px, shrink: 1)

Box A has flex-shrink: 0 → Box A stays 220px, Box B shrinks to 120px:

Box A (220px, shrink: 0)
Box B (220px, shrink: 1)

2. What flex: 1 actually does

flex: 1 = flex-grow: 1; flex-shrink: 1; flex-basis: 0%;

220px, flex-shrink: 0
flex: 1 (grows/shrinks to fill remaining space)
